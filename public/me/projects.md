## Projects

**[Feather](https://github.com/hunterphillips/feather)** — A lightweight chat interface for LLMs, built as a minimalist alternative to Open WebUI or LibreChat. Supports OpenAI, Anthropic, and Google providers simultaneously via a unified Express backend powered by the Vercel AI SDK. Features real-time message streaming, persistent chat history via Zustand, and a clean React/TypeScript/Tailwind frontend using shadcn/ui components.

**[Email Writer](https://github.com/hunterphillips/email-writer)** — A fine-tuning pipeline that trains OpenAI models to write emails in the user's personal style. Processes Gmail exports (Google Takeout .mbox files), automatically stripping signatures, quoted text, and HTML before generating synthetic prompts for context-sparse emails. Splits data 90/10 for training and validation, uploads to OpenAI, and monitors fine-tuning progress. Includes a side-by-side comparison mode to evaluate the fine-tuned model against the base model. Offers both a Streamlit web UI and CLI workflow.

**[SN Mockup](https://github.com/hunterphillips/sn-mockup)** — A rapid prototyping tool for ServiceNow platform UI, allowing developers to build high-fidelity list views, forms, and navigation locally without a live ServiceNow instance. Faithfully implements the Horizon design system using Tailwind design tokens. Supports table import from live instances, full CRUD on local JSON records, and AI-powered field content generation via the Vercel AI SDK (OpenAI, Anthropic, Google, Ollama). Built with React 18, TypeScript, Vite, and React Router v6, with a Vitest test suite.

**[Font Tester](https://github.com/hunterphillips/font-tester)** — A Chrome extension that lets designers and developers preview any live webpage with different Google Fonts applied in real-time, without touching the site's code. Features a popup UI for font selection and persists user preferences across sessions. Available on the Chrome Web Store. Built with vanilla JavaScript, HTML, and CSS using the standard Chrome Extensions manifest architecture.

**[Countdown](https://github.com/hunterphillips/countdown)** — A desktop app that uses demographic inputs, personal health metrics, and the World Population API to calculate and display a real-time countdown to the user's statistically estimated death. Built with Electron and AngularJS, with Chart.js for data visualization and Moment.js for time calculations. Packaged as a native macOS application; 21 stars and two public releases.
